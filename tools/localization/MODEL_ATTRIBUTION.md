# Card localization model attribution

This pipeline runs only locally on a GitHub Actions CPU runner. It does not use
an inference API or an API key.

| Target | Model | License |
| --- | --- | --- |
| Korean | `Helsinki-NLP/opus-mt-tc-big-en-ko` | CC-BY-4.0 |
| Simplified Chinese | `Helsinki-NLP/opus-mt-en-zh` with `>>cmn_Hans<<` | Apache-2.0 |
| Traditional Chinese | `Helsinki-NLP/opus-mt-en-zh` with `>>cmn_Hant<<` | Apache-2.0 |
| Japanese | `Helsinki-NLP/opus-mt-en-jap` | Apache-2.0 |
| Russian | `Helsinki-NLP/opus-mt-en-ru` | Apache-2.0 |

The Korean model's CC-BY-4.0 attribution must be preserved wherever the
translated catalog is distributed.
